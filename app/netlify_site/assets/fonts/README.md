# Tajawal

Unmodified font binaries from the official Google Fonts repository, downloaded
2026-09-23: https://github.com/google/fonts/tree/main/ofl/tajawal

The accompanying OFL.txt is the upstream SIL Open Font License. Exact local
binary hashes are recorded in font-checksums.json. Fonts are served by this app
and cached in its application shell; no Google Fonts request is made at runtime.
