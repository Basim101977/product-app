# مراجعة الأمان ونطاق الرفع

أُجري جرد مساحة العمل: 23,486 ملفاً وقت الفحص، وفحص نصي لـ10,947 ملفاً قابلاً للقراءة، مع استبعاد الاعتمادات وداخل Git والروابط والملفات الثنائية/النصوص الضخمة من الفحص النصي. ظهرت مطابقات أنماط في 492 مساراً، معظمها نسخ متكررة من إعدادات المالك وFirebase. القائمة بلا القيم في WORKSPACE_AUDIT.json. لم تُرفع هذه المسارات الأصلية؛ قائمة سماح .gitignore تختار حزمة التسليم المنقحة فقط.

## ما أزيل أو تغير

| الفئة | المعالجة |
|---|---|
| Firebase browser API key | أزيل من runtime-config وتهيئة Firebase والنسخ التاريخية، ويؤخذ من HATHIR_FIREBASE_API_KEY عند التوليد المحلي. هذا إعداد عميل عام تقنياً، لكنه أزيل امتثالاً لطلب منع رفع أي مفتاح. |
| UID وبريد المالك الحقيقيان | استبدلا بمعلمات وقيم غير حقيقية؛ HATHIR_OWNER_UID وHATHIR_OWNER_EMAIL. ملفات Functions الداعمة تقرأ البيئة؛ القواعد/المتصفح تُهيأ بخطوة توليد محلية. |
| بريد الدعم والاتصال الشخصي | نُقّح؛ HATHIR_SUPPORT_EMAIL للإعداد المستقبلي. |
| بيانات محلية تاريخية في الواجهة | المصدر المختار يحتوي أصلاً عينات اصطناعية معطلة بدلاً من أسماء وحسابات قديمة. لم تُستعد النسخ الخام. |
| محادثات Codex | تصدير نصوص المستخدم والمساعد فقط، مع حجب مقاطع كلمات المرور والمفاتيح والتوكنات والبيانات الشخصية والكود الخام والصور ومخرجات الأدوات. ليست ملفات rollout الخام. |
| Git القديم | نُقّحت commits الثلاثة بموافقة المستخدم، مع حفظ علاقات الآباء والفروع، وتعويض المؤلف بعزو عام للمشروع. GIT_HISTORY_MAP يطابق المعرفات. الأصل المحلي لم يُعدَّل. |
| فيديوهات وصور تعليمية وتسجيلات | مستبعدة لمنع نشر شاشات غير مراجعة أو بيانات أشخاص. بقيت الأيقونات والخطوط وأوزان نماذج الاستدلال العامة؛ لا قوالب وجوه أشخاص. |
| كلمات مرور الاختبار | القيم الاصطناعية الواضحة ليست حسابات حقيقية؛ بقيت حيث يحتاجها الاختبار. لم يُستخدم أي حساب حقيقي لاختبار الحزمة. |

تُحفظ تراخيص المكتبات وعزوها العام كما هي؛ ليست بيانات مستخدمي حاضر. معرفات مشروع Firebase والمناطق وعناوين الخدمات ليست أسراراً، وبقيت لتمييز المشروع الصحيح. هذه المعلومات لا تمنح صلاحية الوصول.

## الملفات السابقة

`instructions/AGENTS.md` مطابق بايتاً لملف development/AGENTS.md الأصلي، وتحققت بصمتاهما. حزمة التسليم السابقة تشمل النصوص والشيفرة الآمنة؛ PREVIOUS_HANDOVER_MANIFEST يبيّن ما نُسخ دون تغيير وما نُقّح وما استُبعد. الاستثناءات من «نسخ كما هي» سببها شرط الأمان والحجم: لا تنسخ runtime أو credentials أو وسائط خاصة لإكمال شكل الأرشيف.

## الحجم والاستبعادات

40 ملفاً في الجرد الأصلي تجاوزت 50 MiB. منها فيديو المساعدة القديم 56,932,025 بايت، محاكي Firestore 136,707,194 بايت، وHATHIR_HANDOVER.zip بحجم 495,149,433 بايت. ليست كلها لازمة للتطوير: المحاكي والاعتمادات يعاد تثبيتها؛ الفيديو يحتاج ضغطاً ومراجعة أو نقلاً خارج Git. كل ملف مرفوع وفروع التاريخ المنقحة خضعت لفحص الحجم، دون رفع ملف يتجاوز الحد.

لا تُرفع .private أو .env أو node_modules أو venv أو build أو dist الحالي أو قواعد البيانات أو ملفات الجلسات الخام أو النسخ المشفرة. تاريخ فروع الاستضافة يحتفظ بملفات dist النصية والأصول الصغيرة الأصلية بعد التنقيح، لأن هذه هي شيفرته التاريخية؛ وليس ناتج build جديداً. لا تُرفع refs/codex الخاصة بلقطات التطبيق؛ أوامر --all ترفع الفروع فقط. تلك اللقطة الداخلية والأصول غير المنقحة محفوظة محلياً.

## التحقق وحدوده

`node tools/audit-handover.cjs --history` يفحص الملفات المجهزة في index وجميع blobs التي تصل إليها الفروع والـtags، بحثاً عن مفاتيح Google/GitHub/OpenAI وOAuth وJWT والمفاتيح الخاصة والبريد غير الاصطناعي، ويتحقق من الحجم. النتيجة الأحدث في SECURITY_SCAN.json. أضيفت مراجعة بشرية للشيفرة ذات الإعدادات وسياسة استبعاد الوسائط والسجلات الخام. هذا فحص أنماط ومراجعة، لا برهان رياضي على غياب كل نوع ممكن من البيانات الشخصية. لا تعد رفع إعدادات محلية مولدة دون إعادة الفحص.

الأصول المحلية وFirebase لم تتغير. لم يتم تدوير مفاتيح أو تغيير كلمات مرور أو مسح بيانات؛ ذلك خارج نطاق نقل المستودع.
