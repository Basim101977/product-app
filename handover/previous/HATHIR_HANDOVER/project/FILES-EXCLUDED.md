# ما استُبعد من حزمة النقل ولماذا

## مستبعد لحماية الخصوصية

- النسخ الخاصة داخل `.private`، ملفات Firestore وحسابات المستخدمين والاستثناءات القديمة الفعلية، والبصمات والصور والحضور الحقيقي.
- مفاتيح DPAPI والنسخ المشفرة نفسها؛ لا يضمن نقل المفتاح المحمي بحساب Windows إمكان فتحه على النوتبوك.
- ملف جلسة Firebase CLI، واعتمادات Google Cloud وADC، ومفاتيح حسابات الخدمة، وملفات البيئة السرية. لا يلزم نقلها لتشغيل الكود والاختبارات؛ يُستعاد الوصول بتسجيل الدخول الصحيح عند الحاجة.
- سجلات النشر الخام وملفات debug والمحاكي، وتقارير الجرد الخام، وملفات جلسات المتصفح وIndexedDB. حزمة الكود ليست وسيلة لنقل حضور لم يُزامَن من الهاتف.
- القيم الموروثة المضمّنة في HTML، وتكرار بريد وكلمة مرور محليين في سطر بيانات اختبار واحد من `tests/personal-ui-regression.cjs`: نُقّحت نسخ التسليم بموافقة المستخدم، وبقي الأصل والمنشور دون تغيير. كل تغيير مقصود موثق في `evidence/privacy-transform.json`، دون إرفاق القيم المحذوفة أو تغيير شروط الاختبار.

## مستبعد لأنه قابل لإعادة التثبيت أو مؤقت

- `node_modules`، وحزم Java/Node/Chromium التنفيذية، وملف محاكي Firestore القابل للتنزيل والتحقق بالتجزئة.
- `.firebase` و`.netlify` وملفات الأدوات المؤقتة وملفات ضغط مصادر الوظائف التي استُخدمت للفحص فقط.
- صور نتائج الاختبارات والسجلات؛ تضم الحزمة تقارير JSON المختارة والموارد الأصلية المطلوبة للتطبيق، ويمكن إعادة إنشاء صور الاختبارات محليًا.

## ليس جزءًا من التطبيق الجاري تطويره

- مشاريع حلول القياسات والنسخ الاختبارية الأخرى والفيديوهات والعروض والبوسترات القديمة. أُرفقت أصول التطبيق الفعلية والدليل HTML الموجود فيه، لا كامل أرشيف المحادثة.
- سكربتات الترحيل وعمليات القطع لمرة واحدة الموجودة بجذر مجلد الترقية الأصلي، مثل `prepare-production.cjs` و`capture-baseline.cjs`. اكتمل دورها السابق، وبعضها ينفذ تغييرات إدارية حساسة؛ ليست اعتماديات بناء أو اختبار التطبيق. توجد مواقعها وأثرها في وثائق الأمان. إعادة استخدامها تحتاج مراجعة ونطاقًا جديدًا، لا تشغيلًا تلقائيًا من الحزمة.
- تاريخ Git: المجلد الأصلي لم يُتعرف عليه كمستودع Git صالح. نُقلت الملفات المحلية نفسها؛ لا يوجد ادعاء بنقل سجل commits غير متاح.

## ما يبقى في الخدمات السحابية

الحسابات وكلمات المرور وخدمات Auth وقاعدة Firestore وHosting والوظائف وإعدادات IAM والفوترة تبقى في المشروع الأصلي. لم يُحذف منها شيء ولم تُغيّر خلال النقل. تسجيل الدخول للنوتبوك لا ينقل تلقائيًا بيانات متصفح هاتف غير متزامنة.

## هل تمنع هذه الاستبعادات التطوير؟

لا تمنع تشغيل الاختبارات والعمل على الكود بعد تثبيت الاعتماديات. **تمنع النشر التلقائي عمدًا**: لا تحتوي الحزمة النسخة الخاصة التي يطلبها حاجز النشر، ويوجد فرق HTML منقّح عن الإصدار المنشور. يجب إعداد نسخة احتياطية وإصدار مراجَع وموافقة واضحة قبل أي نشر لاحق؛ لا تُعطّل الحواجز لتجاوز ذلك.
