# تعليمات كودكس في حزمة حاضر

اقرأ START_HERE.md ثم HANDOVER.md وdocs/KNOWN-ISSUES.md قبل العمل.

- المصدر المعتمد هو source/work/hathir-production-upgrade-20260922/app؛ بقية النسخ القديمة مراجع للاختبار فقط.
- نسخة التسليم من index.html الحالية والتاريخية منقّحة بموافقة المستخدم من بيانات ثابتة قديمة؛ نُقّح أيضًا بريد وكلمة مرور في سطر بيانات اختبار واحد في tests/personal-ui-regression.cjs دون تغيير شروطه؛ راجع evidence/privacy-transform.json. بقية المصدر الأصلي محفوظ. لا تدّعِ تطابق المصدر المنقول حرفيًا مع الأصل، ولا تستبدل بيان بصمات الإصدار المنشور لإخفاء الفرق.
- طلب فتح هذه الحزمة لا يجيز نشرًا أو تغيير حسابات أو IAM أو فوترة أو مسحًا للبيانات. افصل فحصًا محليًا عن أي إجراء سحابي، واطلب موافقة عند الحاجة.
- لا تمسح بيانات الموقع أو الطوابير المعلّقة، ولا تستعد مادة محذوفة أو تعِد ترقيم طالب تلقائيًا.
- لا تحذف حواجز النشر لتجاوز النسخة الاحتياطية المستبعدة من الحزمة. أنشئ إجراء نسخة احتياطية معتمدًا عند استئناف النشر.
- أبقِ معرفات المشروع والمناطق وهوية التخزين والمالك متسقة. لا تغيّر مشروع Firebase بتعديل ملف واحد فقط.
- لا تضمّن رموز الدخول أو ملفات الحسابات أو مفاتيح التشفير في Git أو التقارير أو ZIP.
- استخدم دعم الاختبارات والمعاينة الاصطناعية في support. لا تخدم إعدادات الإنتاج باعتبارها تجربة معزولة.
- سجّل ما اختُبر وما لم يُختبر. نجاح الاختبار المحلي لا يثبت نجاح الصوت أو الكاميرا أو المزامنة على هاتف فعلي.
