## نطاق الوصول الحقيقي

- فُحصت شجرة العمل `C:\Users\USER\OneDrive\Documents\ChatGPT\حاضر`، ومجلدات منتقاة في Desktop/Documents/Downloads لأسماء «Hathir/حاضر» ومواد الورشة. لم أراجع كل ملفات OneDrive أو كل حسابات التخزين السحابي.
- ظهر المستودع المحلي `master` بلا commit وبلا remote، وكل ملفات العمل الأصلية untracked عند الجرد. لذلك لا يوجد رقم commit أو diff تاريخي يُعوَّل عليه؛ بيان SHA-256 هو مرجع الملفات المسلّمة.
- المتاح من المحادثات: نص هذه المحادثة الطويلة، قائمة محادثات التطبيق، ومحتوى محادثة ChatGPT «اقتراح إنشاء QR بالاسم» التي أمكن قراءتها. تعذر جلب محادثة أخرى بعنوان «تجهيز حزمة تسليم المشروع» بأداة القراءة رغم ظهور عنوانها في القائمة. لم تُفحص محادثات غير ظاهرة أو ذاكرة خاصة كاملة.
- لم أستخدم وصولًا إلى Firebase أو ElevenLabs لجلب بيانات جديدة، ولم أنشر أو أغيّر حسابات أو سجلات حية أثناء إعداد الحزمة.
- عدّلت الشيفرة المحلية **قبل وصول طلب الحزمة** لنافذة تأكيد المسح (إصدار ٧٤ المحلي). بعد بدء إعداد الحزمة لم أعدل وظيفة البرنامج. على المستلم إعادة مقارنة هذا التعديل بالإصدار ٧٣ المنشور والتحقق منه قبل أي نشر.

## التحقق بعد النقل

فك الأرشيف ثم نفّذ بأداة Python 3:

```powershell
python VERIFY_BUNDLE.py
```

إذا ظهر اختلاف SHA-256 فلا تستبدل البيان ولا تنشر الشيفرة حتى تفهم السبب. الأرشيف يستبعد عن قصد الاعتماديات القابلة لإعادة التثبيت والبيانات الحية والأسرار والنسخ الاحتياطية الخاصة؛ تُعدَّد في `ACCESS_AND_SECRETS.md`.
