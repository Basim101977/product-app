# أسلوب العمل والقواعد

الواجهة الحالية JavaScript تقليدي وملفات IIFE/إضافات ودوال عامة؛ الخادم CommonJS وstrict mode. الأسماء البرمجية camelCase، الثوابت UPPER_SNAKE_CASE، أسماء الملفات غالباً kebab-case. احترم النمط المحلي للملف ولا تحول المشروع إلى إطار جديد أو تعيد تنسيق آلاف الأسطر مع تعديل محدود.

النصوص للمستخدم بالعربية/الإنجليزية، RTL/LTR، مع اهتمام خاص بمساحة الهاتف وارتفاع الشريط ووضوح الأزرار. طلب المستخدم أن تكون المحاضرة الحديثة قرب الاسم، والحضور بالنقر المزدوج، والمؤشر عامّاً لا عموداً داخل سجل المادة، وألا يزيد ارتفاعه بلا ضرورة. الفحص الخلفي لا يُعرض كرفع مستمر. تصميم الفيديو المطلوب واجهة الهاتف وحدها وصوت عبد الله دون تكرار شرح QR؛ ليس ذلك تكليفاً بإنتاج فيديو في كل تعديل.

لا تعتمد order/تاريخ اسم مجلد لتحديد الإصدار. ابدأ من manifest وأدلة النشر. لا تنسب نتيجة اختبار قديمة إلى تعديل جديد. استخدم بيانات اصطناعية، سجّل الأمر والبيئة والنتيجة وحدودها، ولا تعتبر فحص المتصفح دليلاً على جهاز المستخدم.

قواعد البيانات: معاملات وإيصالات idempotent للعمليات المتكررة، عزل uid لمساحة الحساب، تحقق Auth خادمي رغم Admin SDK، لا إسناد صلاحيات اعتماداً على بريد وحده، ولا استرجاع أو إعادة ترقيم تلقائي عند تضارب القوائم. لا تمسح التخزين المحلي لمعالجة تحديث واجهة. طلب تطوير أو فتح ملف لا يجيز تعديل الحسابات أو IAM أو الفوترة أو مسح البيانات.

لا تتجاوز حواجز النشر ولا تنشر دون نطاق مصرح به ونسخة احتياطية وأدلة جديدة. لا ترفع أسراراً أو إعدادات مولدة بقيم حقيقية أو بيانات الطلبة. حافظ على تراخيص المكتبات كما وردت من المصدر. استخدم فروع codex/ للأعمال الجديدة ما لم يطلب المالك اسماً آخر؛ الفروع المنقولة تحافظ على أسمائها.

نسخة تعليمات AGENTS الأصلية في instructions/AGENTS.md. ملفات التسليم السابقة محفوظة بوصفها تاريخاً، مع التنقيح الأمني حيث لزم. عند تعارض وصف سبتمبر مع هذا التسليم فإن المصدر الأحدث وأدلة نوفمبر هي المرجع. أُجيز صراحة تنقيح التاريخ في هذه المهمة، ولم يُجز حذف الأصل المحلي أو البيانات السحابية.
