# حاضر — تسليم التطوير إلى Claude Code

تاريخ الجرد: 20 نوفمبر 2026، بتوقيت بغداد. ابدأ من هذه الوثيقة ثم ARCHITECTURE وSETUP_AND_RUN وSTATUS_AND_TODO.

«حاضر» تطبيق ويب عربي/إنجليزي لتسجيل حضور الطلبة وإدارة قوائمهم ومحاضراتهم وحساب الغياب. يعمل كتطبيق PWA، ويهدف إلى إبقاء تسجيل الحضور والعمل المحلي متاحين أثناء ضعف الإنترنت، مع رفع العمليات وحفظها ومراجعة تأكيد الخادم عند الاتصال. المستخدم الأساسي هو التدريسي؛ مالك المنصة يعتمد الحسابات ويقدم الدعم. مسؤول القسم قد يجهز القوائم والبطاقات للمشاركة، لكن ذلك لا يمنحه تلقائياً الوصول إلى سجلات جميع التدريسيين.

## المصدر الذي يُستكمل تطويره

`app/` نسخة تسليم من `development/source/work/hathir-department-stage-preview-20261116/app`، الإصدار `v2026.11.18-interaction-167`. تؤكد أدلة النشر المحلية في `evidence/release167-published.json` نشر هذا الإصدار بتاريخ 18 نوفمبر. اسم المجلد الأصلي يحتوي كلمة preview لكنه المصدر الذي استُخدم في النشر اللاحق؛ لا تعتمد الاسم وحده لتحديد الحالة.

نسخة التسليم منقحة من إعدادات الحساب الثابتة ومفتاح Firebase. ليست نسخة استرجاع مطابقة بايتاً للمنشور. لم تتغير الأصول المحلية أو قاعدة البيانات أو الموقع أثناء التسليم. `legacy/alternate-163` مرجع اختبارات ترقية، وليس المصدر الحالي. `previous/` و`instructions/` وثائق سابقة مؤرخة؛ معلومات سبتمبر لا تتغلب على هذه الوثائق.

## الميزات الحالية

- التسجيل بالبريد والاسم وكلمة المرور، تحقق البريد واعتماد المالك، وحفظ توافق الحسابات القديمة وفق سياسة خادمية محددة؛ مساحة خاصة لكل تدريسي.
- إدارة الأقسام والمراحل والسنة الدراسية والمواد وإعدادات الساعات والمدة وسياسة التنبيه والإنذار والرسوب. الأدوات الحالية تسمح بإعداد الأقسام والمراحل دون إعادة فرض القوائم المدنية القديمة.
- إدخال أسماء الطلبة واستيراد جداول Excel، إدارة الحالات الأكاديمية، قوائم تصل إلى 700 صف وفق أعمال أكتوبر واختباراتها. لا يعاد ترقيم الطالب لمجرد الاستيراد أو التحديث.
- مشاركة قائمة خاصة عبر دعوة وقبول، مع فصل القائمة عن سجل حضور المادة. retired-shared-roster يمنع إعادة تفعيل مسار المشاركة المركزية المتقاعد.
- حضور يدوي وبالنقر المزدوج على الاسم، QR للأسماء، بطاقات قديمة مع توافق مدروس، بناء قائمة بالمسح عندما تسمح إعدادات النطاق بذلك. رفض الغموض عند تشابه الأسماء أو عدم تطابق البيانات؛ لا يختار النظام طالباً عشوائياً.
- الوجه اختياري، مع نماذج استدلال محلية؛ قوالب وجوه الأشخاص ليست جزءاً من المستودع. دعم قارئ RFID الذي يحاكي لوحة المفاتيح وNFC ضمن إمكانات الجهاز والمتصفح.
- إنشاء محاضرة من التسجيل، إغلاقها وإلغاؤها وتصحيح حضورها، عرض المحاضرات والسجل التراكمي وتغيير مظهر الخلايا والتصفية والتصدير إلى Excel/PDF.
- IndexedDB وطابور عمليات دائم، إيصالات وإعادة محاولة وعزل بين الأجهزة، حالة واضحة للاتصال والتجهيز والعمليات المعلقة. أحدث إصلاح يبقي فحص الخلفية باللون الأخضر، والرفع الفعلي بالأزرق، دون دوران مشتت؛ لا يغيّر محرك المزامنة.
- PWA وService Worker وتجهيز المكتبات للعمل دون اتصال، تعليمات مساعدة، أصوات مسح، إشعارات Web Push ودعم ورسائل للمالك.
